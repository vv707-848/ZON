# أداة صور الشاشات (ليست جزءًا من التطبيق)

هذه الأداة شغّلت تطبيق زون الحقيقي (كود `lib/` نفسه) والتقطت صور الشاشات المرفقة مع النسخة 1.2.1+4 (`docs/screenshots_v3_1.pdf`: خطة `make_plan_v3_1.py` ثم خطة `make_plan.py`).

- `lib/main.dart` — يشغّل `ZonApp` ويتبع خطة JSON من سيناريوهات. **كل سيناريو يبدأ بجهاز فارغ**، ثم ينشئ حساباته وبياناته عبر كود التطبيق نفسه (`LocalAuth.signUp`، `store.saveListing`، `billing.startPeriod`، `ownerCases`، `notifications`)، ثم يفتح الصفحة وينفذ النقرات والكتابة والتمرير والالتقاط.
- `make_plan.py` — يولّد خطة صور النسخة الثالثة: `python3 make_plan.py plan.json [بادئة-اسم]`.
- `make_plan_v3_1.py` — خطة صور إصلاحات F01–F10 بالطريقة نفسها. تضيف خطوات: `prefs` (بيانات محفوظة بصيغة إصدار سابق ثم تشغيل التطبيق عليها)، `listingJson` (عرض بحقول محددة)، `switch` (دخول حساب آخر أثناء السيناريو)، `payHold`/`payRelease` (إبقاء نتيجة الدفع التجريبي معلّقة ثم إطلاقها)، `copyFile`/`deleteFile` (ملف الاستوديو المؤقت ثم حذفه).

بدائل تُستخدم **في هذه الأداة فقط** وليست في التطبيق:

| البديل | السبب |
|---|---|
| `ShotDictation` | خدمة التعرّف على الكلام في الهاتف لا تعمل في محرك الالتقاط؛ بديل مبرمَج يُظهر حالة الاستماع والكلمات |
| معرض صور وهمي | يعيد ملف صورة من القرص (`ZON_SHOTS_GALLERY`) كأن المستخدم اختاره؛ التطبيق ينسخه إلى مجلد صوره (مجلد مؤقت للأداة) كما يفعل على الهاتف |
| تعليق نتيجة الدفع | `PaymentSimulator.gate` (للاختبارات والأداة فقط) يُبقي الدفع التجريبي في حالة «جارٍ الدفع…» لالتقاط النافذة |
| صف «رسالة جديدة» | النسخة لا تنتج رسائل واردة؛ الصف مضاف بعلامة `demo: true` |
| مضيف حجم الخط `ScaleHost` | يمرر إعداد تكبير الخط (×1.2) كما يفعل الهاتف |
| بدائل الخط | خط التطبيق هو خط النظام (San Francisco على iPhone) وغير موجود في المحرك؛ الأداة تسجّل البدائل نفسها التي تستخدمها الاختبارات من مجلد `ZON_FONTS_DIR` (افتراضيًا `../../test/fonts`) |

الالتقاط نفسه يتم عبر محرك Flutter بلا شاشة يجيب على القناة `fshot` (`capture:<name>`، `metrics:<w>,<h>,<dpr>`، `log:…`، `exit`)، وهذا المحرك **ليس ضمن المشروع**. عند تشغيل الأداة بـ `flutter run` العادي تُنفَّذ السيناريوهات دون حفظ صور. الإثبات السلوكي (الدفع، الرصيد، الصلاحيات، الحفظ) في اختبارات `test/`، لا في الصور.
